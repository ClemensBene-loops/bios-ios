Privacy Policy

BIOS (personal health data project) · Last updated: 28 September 2026

BIOS is a private, non-commercial application operated by a single individual (the "operator") to analyse their own health data. It has no other users and is not offered to the public.

Data accessed

  • WHOOP data (recovery, cycles, sleep, workout and profile information), accessed with the operator's explicit authorisation via the official WHOOP API.
  • The operator's own medical device data: continuous glucose monitoring, insulin pump and Loop data, and blood pressure readings.
  • Google user data, limited to two Google Calendar scopes (see below).
  • Public environmental data (wastewater surveillance, pollen forecasts), which contains no personal data.

Google user data

BIOS requests only these Google Calendar scopes:

  • calendar.app.created: BIOS creates and manages only its own secondary calendar named "BIOS" and writes day-level health status events into it (for example "recovery low" or "possible infection"). It never reads, changes or deletes events in any other calendar.
  • calendar.freebusy: BIOS reads only busy/free time ranges, without titles, descriptions, attendees, locations or any other event details. It uses them solely to avoid sending notifications during meetings.

Google user data is used only to provide these features to the operator. It is not sold, not used for advertising, not used to build profiles, not used to develop, improve or train generalised AI or machine learning models, and not read by anyone other than the operator.

BIOS's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

How data is used

All data is used solely for the operator's personal health analysis, visualisation and notifications, for example to identify patterns in the operator's own physiology.

Where data is processed and stored

Data is processed and stored on the operator's own server (a virtual machine rented from Microsoft Azure and used only for this project) and on the operator's personal devices (computer and iPhone). The server's interface for the iOS app is protected by a secret access token and encrypted in transit (HTTPS). Health data is never published.

Sharing

No data is sold, rented or shared, and no data is used for advertising, for profiling of others or for any commercial purpose. Data is not transferred to third parties, except to the service providers strictly needed to run BIOS: the hosting provider of the server (Microsoft Azure), Apple's push notification service to deliver notifications to the operator's iPhone, and Google Calendar itself, which stores the events BIOS writes into its own "BIOS" calendar.

Retention and deletion

Data is kept only as long as the operator needs it for personal analysis. On request, all data received from WHOOP or Google is deleted from the server and the operator's devices. The "BIOS" calendar and its events can be deleted at any time in Google Calendar.

Revoking access

  • Google: remove BIOS at myaccount.google.com/permissions.
  • WHOOP: revoke the app's access in the WHOOP account settings.

After revocation BIOS can no longer access new data from that service.

Contact

For questions about this application or to request deletion of data, contact the operator via the support email address shown on the Google consent screen.
